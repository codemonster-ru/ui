# CodeMonster UI showcase

Internal Vue integration consumer for CodeMonster UI and the retained VueForge product packages.

## Run

```bash
npm run dev
```

The app opens directly on Components and exposes six focused showcase sections:

- Components
- Colors
- Layout
- Icons
- CodeBlock
- Playground

Components and Layout use `@codemonster-ru/ui-vue`, `@codemonster-ru/ui-css`, and
`@codemonster-ru/ui-tokens`. The application shell, theme tooling, Icons, CodeBlock, and Playground
remain separate VueForge-owned product surfaces according to the migration ownership decisions.

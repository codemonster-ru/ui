# Security policy

Send suspected vulnerabilities privately to the CodeMonster organization contact
[admin@codemonster.net](mailto:admin@codemonster.net). Keep vulnerability details, credentials,
and customer data out of public issues and pull requests.

Include the affected package and version or commit, the integration you use, the observed
impact, and steps to reproduce the issue. Remove secrets and personal data from examples and
attachments.

For ordinary bugs and usage questions, use [GitHub Issues](https://github.com/codemonster-ru/ui/issues).

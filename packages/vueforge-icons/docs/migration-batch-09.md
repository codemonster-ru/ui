# Icon Migration Batch 09

Status: approved by the project owner on 2026-08-01.

## Scope

- `copy`: replace the legacy solid stack with two offset outline files; the front file uses the
  approved folded-corner construction and the rear file keeps a controlled open overlap.
- `clipboard`: replace the solid board with an outline container and a separate rounded clip.

Both public names and semantics are unchanged. The approved 30-icon reference set and migration
batches 02–08 remain frozen and are not expanded or modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 9 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

# Icon Migration Batch 16

Status: approved by the project owner on 2026-08-01.

## Scope

- `terminal`: replace the off-center solid command mark with a balanced outline prompt and
  underscore.
- `code`: normalize the legacy 512-unit strokes into symmetric angle operators and a centered
  slash.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–15
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 16 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

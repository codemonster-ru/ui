# Icon Migration Batch 14

Status: approved by the project owner on 2026-08-01.

## Scope

- `filter`: replace the dense solid shape with a centered outline funnel.
- `funnelX`: derive the clear-filter action from the same funnel and add a compact rounded x mark.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–13
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 14 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

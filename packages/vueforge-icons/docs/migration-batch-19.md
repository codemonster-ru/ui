# Icon Migration Batch 19

Status: approved by the project owner on 2026-08-01.

## Scope

- `expand`: replace the solid diagonal arrows with a symmetric outward pair and canonical L-shaped
  corner heads.
- `collapse`: derive the inverse inward action from the same keyline and head dimensions.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–18
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 19 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

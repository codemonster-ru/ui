# Icon Migration Batch 21

Status: approved by the project owner on 2026-08-01.

## Scope

- `link`: replace the dense solid chain with two large interlocking C-shaped links on a shared
  diagonal axis.
- `externalLink`: replace the solid object with an open rounded frame and the canonical outbound
  arrow.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–20
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 21 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

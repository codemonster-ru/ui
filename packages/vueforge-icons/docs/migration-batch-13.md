# Icon Migration Batch 13

Status: approved by the project owner on 2026-08-01.

## Scope

- `logIn`: replace the dense solid action with a right-side door contour and an entering arrow.
- `logOut`: replace the mismatched solid construction with the mirrored door contour and an exiting
  arrow.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–12
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 13 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

# Icon Migration Batch 18

Status: approved by the project owner on 2026-08-01.

## Scope

- `building`: replace the dense solid block with a rounded outline facade, four square windows, and
  a centered doorway.
- `briefcase`: replace the split solid mass with a rounded case, a centered handle, and a controlled
  clasp interruption.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–17
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 18 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

# Icon Migration Batch 02

Status: approved by the project owner on 2026-07-31.

## Scope

- `arrowLeft`, `arrowUp`: complete the canonical arrow rotations approved through `arrowRight` and
  `arrowDown`.
- `chevronLeft`, `chevronUp`: complete the canonical chevron rotations approved through
  `chevronRight` and `chevronDown`.
- `caretLeft`, `caretRight`, `caretUp`, `caretDown`: replace the legacy filled triangles with one
  compact outline primitive in four rotations.

All eight names and semantics are unchanged. The approved 30-icon reference set remains frozen and
is not expanded by this batch.

## Review route

Open the playground at `/icons` and select `Batch 2 review`. Evaluate old, new, and overlay samples
at 16, 20, 24, and 32 px, using 20 px as the primary decision size. The geometry was accepted by the
project owner. Future changes to these icons require a new comparison revision rather than silently
replacing this baseline.

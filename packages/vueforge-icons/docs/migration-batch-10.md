# Icon Migration Batch 10

Status: approved by the project owner on 2026-08-01.

## Scope

- `inbox`: replace the dense solid tray with a centered outline container and a clear receiving
  notch.
- `archive`: replace the split solid mass with an outline box, a separate rounded lid, and a
  centered handle.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–09
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 10 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

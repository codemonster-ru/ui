# Icon Migration Batch 23

Status: approved by the project owner on 2026-08-01.

## Scope

- `bookmark`: replace the solid ribbon with a tall rounded outline and broad centered notch.
- `heart`: replace the dense silhouette with balanced upper lobes and a stable lower point.
- `star`: replace the solid mark with a symmetric five-point outline and open central counter.

All three icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins.
Their public names and semantics are unchanged. The approved reference set and migration batches
02–22 remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 23 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

# Icon Migration Batch 24

Status: approved by the project owner on 2026-08-01.

## Scope

- `shield`: replace the solid mass with a symmetric protective outline and stable lower point.
- `key`: replace the solid object with a large round head, broad diagonal shaft, and one readable
  stepped tooth.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–23
remain frozen and are not modified by this batch.

The approved `key` intentionally uses a larger-than-default visual box so its round head, broad
shaft, and rectangular tooth remain distinct at small sizes. The project owner accepted the audit
bounds warnings after visual review.

## Review route

Open the playground at `/icons` and select `Batch 24 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

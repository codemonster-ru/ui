# Icon Migration Batch 04

Status: approved by the project owner on 2026-07-31.

## Scope

- `info`, `question`: replace the legacy standalone solid symbols with canonical rounded strokes.
- `questionCircle`, `alertCircle`, `checkCircle`, `xCircle`: use one shared circular container with
  consistent internal feedback symbols.
- `ban`: use the same circular container and the approved diagonal stroke language.

The approved 30-icon reference set and migration batches 02–03 remain frozen and are not expanded
or modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 4 review`. Evaluate old, new, and overlay samples
at 16, 20, 24, and 32 px, using 20 px as the primary decision size. The geometry was accepted by the
project owner. Future changes to these icons require a new comparison revision rather than silently
replacing this baseline.

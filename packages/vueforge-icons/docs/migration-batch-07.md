# Icon Migration Batch 07

Status: approved by the project owner on 2026-08-01.

## Scope

- `clock`: replace the legacy solid face with the canonical circular container and restrained hour
  and minute hands.
- `history`: reuse the same hands inside an open counterclockwise return arrow.

Both public names and semantics are unchanged. The approved 30-icon reference set and migration
batches 02–06 remain frozen and are not expanded or modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 7 review`. Evaluate old, new, and overlay samples
at 16, 20, 24, and 32 px, using 20 px as the primary decision size. The geometry was accepted by the
project owner. Future changes to these icons require a new comparison revision rather than silently
replacing this baseline.

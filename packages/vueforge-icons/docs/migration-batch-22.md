# Icon Migration Batch 22

Status: approved by the project owner on 2026-08-01.

## Scope

- `bars`: normalize the menu trigger to three equal horizontal strokes with a shared reach and
  vertical rhythm.
- `ellipsis`: normalize the overflow trigger to three larger equal stroke circles on the horizontal
  centerline.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–21
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 22 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

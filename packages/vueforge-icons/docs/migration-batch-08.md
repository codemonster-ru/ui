# Icon Migration Batch 08

Status: approved by the project owner on 2026-08-01.

## Scope

- `refresh`: replace the legacy solid cycle with two balanced circular arrows.
- `rotateRight`: use one clockwise circular arrow for explicit rotate, redo, or repeat semantics.
- `circleNotch`: use an open circular stroke without an arrow for loading and busy states.

All public names and semantics are unchanged. The approved 30-icon reference set and migration
batches 02–07 remain frozen and are not expanded or modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 8 review`. Evaluate old, new, and overlay samples
at 16, 20, 24, and 32 px, using 20 px as the primary decision size. The geometry was accepted by the
project owner. Future changes to these icons require a new comparison revision rather than silently
replacing this baseline.

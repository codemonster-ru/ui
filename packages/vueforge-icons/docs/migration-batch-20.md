# Icon Migration Batch 20

Status: approved by the project owner on 2026-08-01.

## Scope

- `sliders`: replace the solid controls with three equal outline tracks and separated circular
  handles.
- `sort`: replace the dense filled shapes with symmetric closed up/down triangles on a shared
  vertical axis.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–19
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 20 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

# Icon Migration Batch 03

Status: approved by the project owner on 2026-07-31.

## Scope

- `minus`: align the remaining basic system symbol with the canonical outline stroke.
- `userPlus`, `userMinus`, `userCheck`: derive user actions from the approved `user` geometry.
- `unlock`: derive the open state from the approved `lock` geometry.
- `fileText`, `folderOpen`: extend the approved content family without changing names or semantics.

The approved 30-icon reference set and migration batch 02 remain frozen and are not expanded or
modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 3 review`. Evaluate old, new, and overlay samples
at 16, 20, 24, and 32 px, using 20 px as the primary decision size. The geometry was accepted by the
project owner. Future changes to these icons require a new comparison revision rather than silently
replacing this baseline.

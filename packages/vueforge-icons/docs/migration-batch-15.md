# Icon Migration Batch 15

Status: approved by the project owner on 2026-08-01.

## Scope

- `server`: replace the dense solid racks with two equal outline units and restrained status marks.
- `hardDrive`: replace the split solid mass with one drive enclosure, a lower status panel, and the
  same indicator language.

Both icons use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–14
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 15 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

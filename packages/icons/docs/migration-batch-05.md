# Icon Migration Batch 05

Status: approved by the project owner on 2026-07-31.

## Scope

- `eye`: replace the legacy masked solid with a calm outline eye and centered circular pupil.
- `eyeSlash`: retain the same eye geometry and add one canonical rounded diagonal for the hidden
  state.

Both public names and semantics are unchanged. The approved 30-icon reference set and migration
batches 02–04 remain frozen and are not expanded or modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 5 review`. Evaluate old, new, and overlay samples
at 16, 20, 24, and 32 px, using 20 px as the primary decision size. The geometry was accepted by the
project owner. Future changes to these icons require a new comparison revision rather than silently
replacing this baseline.

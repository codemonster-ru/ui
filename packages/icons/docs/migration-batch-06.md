# Icon Migration Batch 06

Status: approved by the project owner on 2026-08-01.

## Scope

- `sun`: replace the legacy solid center and rays with one outlined ring and eight equal rounded
  rays.
- `moon`: replace the masked solid with one clean crescent contour.
- `circleHalf`: replace the full-canvas solid with a circular contrast outline and one filled half.

All public names and semantics are unchanged. The approved 30-icon reference set and migration
batches 02–05 remain frozen and are not expanded or modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 6 review`. Evaluate old, new, and overlay samples
at 16, 20, 24, and 32 px, using 20 px as the primary decision size. The geometry was accepted by the
project owner. Future changes to these icons require a new comparison revision rather than silently
replacing this baseline.

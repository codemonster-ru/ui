# Icon Migration Batch 11

Status: approved by the project owner on 2026-08-01.

## Scope

- `arrowLeftLong`, `arrowRightLong`, `arrowUpLong`, and `arrowDownLong`: normalize the legacy
  512-unit strokes into four rotationally symmetric long arrows derived from the approved
  directional geometry.

The arrows use the canonical 24-unit canvas, 2-unit stroke, round terminals, and round joins. Their
public names and semantics are unchanged. The approved reference set and migration batches 02–10
remain frozen and are not modified by this batch.

## Review route

Open the playground at `/icons` and select `Batch 11 review` to compare the preserved old baseline,
approved geometry, and overlay samples at 16, 20, 24, and 32 px.

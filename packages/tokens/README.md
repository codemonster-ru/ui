# CodeMonster UI Tokens

Framework-independent design tokens and theme serialization for CodeMonster UI.

## Status

This package currently provides the publishable package boundary. Primitive and semantic tokens,
theme presets, generated CSS, and serialization APIs are added by their dedicated roadmap items.

The package does not depend on Vue or another UI framework.

## Installation

```bash
npm install @codemonster-ru/ui-tokens
```

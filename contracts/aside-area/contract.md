# Aside area

Render complementary content in an aside with a padded inner region. Use `cm-layout-area--plain` for a transparent surface with no visible divider. Name the landmark when the document has multiple asides of the same kind.

The [canonical HTML](./cases/default.html) uses `@codemonster-ru/ui-css/layout-areas.css` and shared tokens.
The component has no runtime controller or required JavaScript.

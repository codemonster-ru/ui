# Error layout

A section with optional status code, heading, explanation and recovery actions. A numeric zero is a code. Use links when recovery navigates and buttons for local actions. If the error replaces existing content, the host owns focus or announcements.

The [canonical HTML](./cases/default.html) uses `@codemonster-ru/ui-css/page-layouts.css` and shared tokens.
The component has no runtime controller or required JavaScript.

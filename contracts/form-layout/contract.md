# FormLayout

Put field wrappers directly inside `cm-form-layout` and choose a stacked, horizontal, or
responsive modifier. Responsive layout stacks the fields in containers under 768 pixels and
places labels beside controls at wider sizes. Use `--cm-form-layout-label-width` to set the label
track. The wrapper preserves document order and leaves submission and validation to the form.

# Getting started

`@codemonster-ru/vueforge-icons` is the Vue 3 icon renderer and generated icon catalog used by
VueForge. Use `VueIconify` when an icon name is known at runtime, and use the metadata exports to
build validation, search, or picker interfaces.

Start with the [installation guide](./installation.md), then open the
[VueIconify component guide](./components/vue-iconify/index.md) or browse the
[icon catalog](./icons.md).

The package requires Vue 3.5 and supports Node.js 18 or newer. Browser imports include the icon
styles automatically; SSR imports use the CSS-free Node condition.

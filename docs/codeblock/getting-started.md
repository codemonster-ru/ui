# Getting started

CodeBlock is a standalone Vue 3.5 component for accessible code presentation, deferred syntax
highlighting, copy interactions, and light/dark theme inheritance.

The package has no modern root export. Use `/view` for the component/plugin surface and
`/highlight` for direct highlighting helpers.

Continue with:

- [Installation](./installation.md) for npm/pnpm/Yarn, CSS delivery, language loading, and SSR.
- [CodeBlock component](./components/code-block/index.md) for usage, API, features, and theming.
- [Public API](./api/index.md) for the `/view` and `/highlight` exports.

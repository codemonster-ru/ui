# Theming

`VfMenu` uses the overlay and dropdown token namespaces for its surface and item states.

| Token family                        | Purpose                                           |
| ----------------------------------- | ------------------------------------------------- |
| `--vf-menu-*`                       | Menu spacing and minimum width.                   |
| `--vf-dropdown-item-*`              | Item text, active, focus, and interaction states. |
| `--vf-field-padding-*`              | Menu item padding.                                |
| `--vf-surface-gap-compact`          | Gap between an item icon and label.               |
| `--vf-color-status-danger-subtle-*` | Danger item color and background.                 |

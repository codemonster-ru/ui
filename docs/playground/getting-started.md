# Getting started

Vue 3 UI adapter component/plugin for interactive playground sessions, built on top of
`@codemonster-ru/vueforge-playground-core`.

Use the `/ui` entry when an application needs the built-in tabs, CodeBlock source view, preview,
and console. Use the `/runtime` entry only when implementing a custom playground interface around
the session API.

Continue with:

- [Installation](./installation.md) for dependencies, Core CSS, plugin setup, lazy loading, and SSR.
- [Playground examples](./components/playground/features.md) for sandbox and component modes.
- [Component API](./components/playground/api.md) for props, events, renderers, and the custom layout slot.
- [Theming](./components/playground/theming.md) for inherited, explicit, and sandboxed themes.

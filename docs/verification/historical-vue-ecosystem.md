## Archived layouts consumer

A fresh npm consumer installed these release versions matching the historical reference:
`vueforge-layouts@2.1.2`, `vueforge-core@2.4.0`, `vueforge-icons@3.2.0`,
`vueforge-theme@2.0.1`, and Vue and its server renderer at `3.5.45`. A Node SSR check
installed the root `VueForgeLayouts` plugin, rendered a collapsed `VfAppShell` through a
scoped slot, and rendered `VfContainer` from its direct ESM subpath. It loaded the CommonJS root
and resolved both the full and container stylesheet paths. The custom preset prefix emitted
both its custom shell sidebar width and the historical alias. The [layout package README](../../packages/layouts/README.md)
includes the installation command.

`useBreakpoint`, `useBreakpoints`, `useBreakpointValue` and `useScrollLock`. The current split
keeps pure rules in `ui-runtime/core` and shared themes in `ui-tokens`, with no automatic Vue
plugin registration. These boundaries require a separate export and consumer check. Historical
component subpaths, auto-applied CSS, `critical.css`, CJS and theme entries cannot be inferred
from the current root-only ESM Vue export.

## Evidence and next executable tasks

- Vue behavior for the restored composition group is in
  `packages/vue/src/components/historical-compositions.test.ts`. Existing package suites for
  forms, navigation, data tables, overlays, layout primitives and advanced inputs cover the
  current contracts. Extend those owning suites when restoring the corresponding historical items.
- DataTable's focused Vue suite passed all 18 tests on Node 24, including scoped content,
  manual requests, sorted client pages, off-page selection, controlled expansion, mask and
  skeleton states. The navigation suite passed 10 tests after restoring routed links.
- DataTable resizing passed 20 Vue tests, 26 runtime and package checks, and seven built SSR
  checks. Chrome exposed the labelled splitter in both adapters. Keyboard, pointer and autosize
  kept the overall width at 576 px while updating the exposed splitter value. The authored
  separator passed the canonical accessibility gate.
- DatePicker keyboard, locale, and form checks passed for Vue and Vanilla. A Vue production
  build passed all 22 advanced-input SSR checks, including nine DatePicker markup cases
  and disabled, readonly, and range submission. Eighteen Vue calendar tests and twelve
  runtime calendar/form tests passed. Chrome keyboard checks covered range selection,
  multiple toggling, and month and year paging with focus return in both adapters using
  light and dark themes. Chrome also verified native hour and minute changes, clamping
  to 10:30 on the following day, and Escape focus return in Vue and Vanilla. With
  a body portal, both adapters aligned the calendar to the trailing edge 2 px below the
  trigger. Arrow and Enter selected August 14 and restored trigger focus.
- Tooltip passed six Vue interaction tests and four built canonical markup cases. Chrome used the
  authored button in Vue light and Vanilla dark. Tab showed the body portal 10 px below the
  trigger and Escape hid it while retaining focus. Both triggers referenced the portal ID.
- New CSS subpaths are covered by the distributed package test and by the aggregate-style
  reachability check. Historical component styles use VueForge selectors and tokens. The new
  counterparts use the existing shared CodeMonster selectors and tokens. CSS class name and
  custom property migration for legacy consumers remains open.
- Prioritize DatePicker, DataTable and field/overlay APIs. Compare the original showcase
  states in the exact-reference build with equivalent states in both current platforms before
  marking visual or accessibility acceptance complete.
